# Active original cursor assets

Default: initial-custom-clean.svg and initial-custom-clean.png, independently authored for Workwithkenn and approved by the owner. The refined pointer is tilted, rounded and tailless, with a warm-white #F4F4EF body, dark #090A0C outline and cobalt #4D7CFE inset. Both files are 36×36 px; the SVG uses a 29×29 viewBox, a -14° rotation and a 2-unit rounded outline. The active CSS hotspot is 4,4 for both SVG and PNG. No external cursor path, image tracing, Chrome Pointer pixels, recoloring of third-party art or other third-party geometry was used to create it. The existing Chrome Pointer is an aesthetic reference only, never an artwork input. No glow, gradient, shadow, metallic effect or animation. PNG is an exact raster fallback of this SVG.

Interactive: the owner-approved hand.svg and hand.png remain byte-identical: transparent interior, thin warm-white contour over dark contrast edge, 28×28 and fingertip hotspot 10,3. These are the existing original Workwithkenn artwork, not a third-party pack.

Text/editable areas and special states retain native text, not-allowed, progress, grab/grabbing and resize behavior. The existing fine-pointer/hover and forced-colors/contrast gating is unchanged. No JS tracking or runtime dependency.

Production CSS references only initial-custom-clean.svg/PNG (with the tilted-36 cache version) and hand.svg/PNG. The foundation original-arrow.svg/PNG remain retained but inactive. Old Chrome Pointer CUR/PNG/provenance, old arrow.svg/PNG and Azure Aura files remain untouched, unused and must stay excluded from the proposed public checkpoint. Unknown Chrome Pointer rights are not reassigned or cleared by replacing its active use. The original active artwork introduces no third-party cursor asset dependency.
