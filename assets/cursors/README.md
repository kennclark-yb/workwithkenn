# Active original cursor assets

Default: original-arrow.svg and original-arrow.png, independently authored for Workwithkenn on a 32px coordinate grid. The path uses a broad arrowhead and short angled tail, a flat #F4F4EF fill and 1.2px #111318 outline. Dimensions 32×32; hotspot 4,3. No external cursor path, image tracing, Chrome Pointer pixels, recoloring of third-party art or other third-party geometry was used to create it. The existing Chrome Pointer is an aesthetic reference only, never an artwork input. No glow, gradient, shadow, metallic effect or animation. PNG is an exact raster fallback of this SVG.

Interactive: the owner-approved hand.svg and hand.png remain byte-identical: transparent interior, thin warm-white contour over dark contrast edge, 28×28 and fingertip hotspot 10,3. These are the existing original Workwithkenn artwork, not a third-party pack.

Text/editable areas and special states retain native text, not-allowed, progress, grab/grabbing and resize behavior. The existing fine-pointer/hover and forced-colors/contrast gating is unchanged. No JS tracking or runtime dependency.

Production CSS references only original-arrow.svg/PNG and hand.svg/PNG. Old Chrome Pointer CUR/PNG/provenance, old arrow.svg/PNG and Azure Aura files remain untouched, unused and must stay excluded from the proposed public checkpoint.
