# YOINK screenshots

Real captures of the running PySide6 application, using synthetic conversation
content and `https://chatgpt.com/share/example`. That URL is a placeholder, not a
live conversation. These are not mockups or generated UI.

Captures use the actual GUI and extraction worker with a synthetic page result
supplied by a temporary development fixture, which is not shipped. To replace
them later, capture the current source app or a freshly built YOINK with safe
sample content. Use these filenames so README links continue to work. Capture
only the application window, obscure any real share URL, and use made-up notes.

The released V1 extracts ChatGPT shared conversations into Markdown with role filters, split modes, Preview, per-part/Copy All and a session Scratchpad. The owner manually selects useful content and prepares the handoff separately.
